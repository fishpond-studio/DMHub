# 域名管理

## 添加域名

1. 进入「域名」页面
2. 点击「添加域名」
3. 填写域名名称，关联 DNS 服务商配置
4. 可选填到期时间和标签
5. 可点击「WHOIS 自动获取」自动查询到期日期
6. 保存后系统自动从服务商同步解析记录

## 域名信息

| 字段 | 说明 |
|------|------|
| 名称 | 域名全名（如 `example.com`） |
| 服务商 | 关联的 DNS 服务商配置 |
| 到期时间 | WHOIS 查询或手动设置 |
| 状态 | `active` / `expiring` / `expired` |
| 分组 | 按项目分组 |
| 标签 | 自定义标签（如 `生产环境`、`测试`） |

## 域名状态

| 状态 | 条件 |
|------|------|
| `active` | 正常，距过期 > 30 天 |
| `expiring` | 距过期 ≤ 30 天 |
| `expired` | 已过期 |

## 分组与标签

- **标签** — 为域名添加标签，便于分类管理
- **分组** — 按项目对域名分组
- **置顶** — 点击 📌 图标将重要域名置顶，置顶域名始终排在列表最前面
- 在域名列表页可按分组或标签筛选

> 域名标签和分组修改仅限 **admin**。member 即使有 `dns_edit` 权限也不可修改这些元数据。

## 导出域名

在域名列表页点击 **"导出"** 按钮：

- **CSV** — 导出为 Excel 兼容的 CSV 文件（含 BOM 头，中文无乱码）
- **JSON** — 导出原始 JSON 数据

在域名详情页的 DNS 记录表上方也有 **"导出"** 按钮，可将当前域名的所有解析记录导出为 CSV。

## 域名详情

点击域名进入详情页，包含：

- 解析记录列表
- 快照历史
- WHOIS 信息
- 域名设置（到期时间、提醒节点、标签等）

## 批量操作

- 批量删除域名
- 批量修改分组或标签
