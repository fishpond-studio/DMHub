# DNS 解析记录管理

## 记录类型

DMHub 支持以下 DNS 记录类型：

| 类型 | 说明 | 值示例 |
|------|------|--------|
| A | IPv4 地址 | `192.168.1.1` |
| AAAA | IPv6 地址 | `2001:db8::1` |
| CNAME | 别名指向 | `example.com` |
| MX | 邮件交换 | `mail.example.com` |
| TXT | 文本记录 | `v=spf1 include:...` |
| NS | 域名服务器 | `ns1.example.com` |
| SRV | 服务记录 | `10 60 5060 sip.example.com` |
| CAA | 证书颁发机构授权 | `0 issue "letsencrypt.org"` |

## 记录字段

| 字段 | 说明 |
|------|------|
| 主机记录 | 记录名称（如 `www`、`@`、`*`） |
| 记录类型 | A / AAAA / CNAME / MX / TXT / NS / SRV / CAA |
| 记录值 | 记录内容 |
| TTL | 生存时间（秒） |
| 优先级 | MX / SRV 优先级 |
| 代理状态 | 是否启用服务商代理（Cloudflare 等） |

## 操作流程

### 创建记录

1. 进入域名详情 → 「解析记录」Tab
2. 点击「添加记录」（或使用 [DNS 记录模板](/guide/dns-templates) 快速填充）
3. 选择记录类型，填写主机记录和值
4. 设置 TTL 和优先级（如适用）
5. 保存 → 自动同步到服务商 API

::: tip DNS 记录模板
常用配置（Gmail、Office 365、Cloudflare CDN 等）可使用预设模板快速创建，无需手动记忆每条记录。详见 [DNS 记录模板](/guide/dns-templates)。
:::

### 修改记录

1. 在记录列表点击「编辑」
2. 修改需要更新的字段
3. 保存 → 自动同步到服务商 API
4. 自动创建变更快照

### 删除记录

1. 在记录列表点击「删除」
2. 二次确认
3. 删除 → 自动同步到服务商 API
4. 自动创建变更快照

### 同步记录

点击「同步」从服务商拉取最新解析记录，与本地数据库对比后更新。

## 自动快照

每次创建 / 修改 / 删除操作都会自动创建 `on_change` 类型的快照。可在「快照」Tab 查看历史版本。

## 权限控制

| 操作 | admin | member（dns_edit） | member（dns_readonly） | guest |
|------|-------|-------------------|----------------------|--------|
| 查看记录 | ✅ | ✅ | ✅ | ❌ |
| 创建 / 修改 / 删除 | ✅ | ✅ | ❌ | ❌ |

> member 的操作受子域名匹配模式限制，只能操作指派范围内的记录。
