# 批量导入

DMHub 支持通过 CSV 文件批量导入域名和解析记录，适合从其他平台迁移。

## 导入域名

### 步骤

1. 进入「批量导入」页面
2. 点击「下载域名 CSV 模板」
3. 按模板填写域名信息
4. 上传 CSV 文件
5. 查看导入结果

### 域名 CSV 格式

| 列 | 必填 | 说明 |
|----|------|------|
| name | 是 | 域名名称 |
| providerId | 否 | DNS 服务商 ID（留空则不同步） |
| expiresAt | 否 | 到期时间（ISO 8601 格式） |
| groupName | 否 | 分组名称 |
| tags | 否 | 标签（逗号分隔） |
| status | 否 | 状态（active / expiring / expired） |

### 导入结果

| 结果 | 说明 |
|------|------|
| 成功 | 域名已创建并关联 DNS 服务商 |
| 跳过 | 域名已存在，跳过导入 |
| 错误 | 数据格式错误或服务商同步失败 |

## 导入解析记录

### 步骤

1. 进入「批量导入」→ 「导入记录」Tab
2. 选择目标域名
3. 点击「下载记录 CSV 模板」
4. 按模板填写记录信息
5. 上传 CSV 文件
6. 查看导入结果

### 记录 CSV 格式

| 列 | 必填 | 说明 |
|----|------|------|
| recordType | 是 | 记录类型（A / AAAA / CNAME / MX / TXT / NS / SRV / CAA） |
| name | 是 | 主机记录（如 `www`、`@`） |
| value | 是 | 记录值 |
| ttl | 否 | TTL（秒，默认 600） |
| priority | 否 | 优先级（MX / SRV） |
| proxied | 否 | 是否代理（Cloudflare，默认 false） |

## 注意事项

- CSV 文件编码必须为 UTF-8
- 单文件最多 1000 行
- 导入前请确认 DNS 服务商配置已就绪
- 导入失败的行会标注具体原因
- 导入操作会记录到操作日志
