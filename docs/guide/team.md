# 团队管理

进入「设置 → 团队设置」管理团队信息、成员和注册策略。

## 基本信息

| 设置 | 说明 |
|------|------|
| 团队 Logo | PNG / JPG / SVG，≤ 1MB，推荐 128×128px |
| 团队名称 | 显示在仪表盘和主页 |
| 副标题 | 显示在主页团队名称下方 |
| 站点 URL | 影响 OAuth 回调和 Cookie 域名 |
| 底栏内容 | 支持 Markdown / HTML，显示在主页底部 |
| 背景图片 | PNG / JPG / WEBP / GIF，≤ 5MB |

## 注册与邀请

| 设置 | 说明 |
|------|------|
| 邀请码开关 | 默认开启，关闭后注册无需邀请码 |
| 开放注册 | 关闭后禁止新用户注册 |
| 生成邀请码 | 可设置过期时间和使用次数 |
| 重新生成 | 会使现有邀请码全部失效（需二次确认） |

## 成员管理

| 操作 | 说明 |
|------|------|
| 查看成员 | 查看所有团队成员列表 |
| 修改角色 | 更改成员角色（admin / member / guest） |
| 启用 / 禁用 | 禁用时自动吊销该成员所有 refresh token |
| 移除成员 | 移除后失去所有指派权限（至少保留一个管理员） |

## 角色说明

| 角色 | 权限范围 |
|------|---------|
| admin | 全局管理：所有功能 |
| member | 指派范围内的 DNS 记录管理 |
| guest | 仅查看（无管理权限） |

## 站外公告

- 公告内容支持 Markdown 或 HTML
- 留空则不显示
- 显示在登录页面

## 操作日志

所有团队设置变更会记录到操作日志，包括：

- 注册策略变更
- 成员角色变更
- 成员启用 / 禁用
- 团队信息修改
