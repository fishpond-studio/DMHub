# 快照与回滚

DMHub 提供解析记录的版本管理功能，支持手动快照和变更时自动快照。

## 快照类型

| 触发方式 | trigger 值 | 说明 |
|----------|------------|------|
| 手动创建 | `manual` | 用户主动创建 |
| 解析变更 | `on_change` | 创建 / 修改 / 删除记录时自动创建 |

## 快照内容

每个快照保存域名下所有解析记录的完整副本（JSONB），包括：

- 记录类型、主机记录、值
- TTL、优先级
- 代理状态

## 快照操作

### 创建快照

**手动创建：**

1. 进入域名详情 → 「快照」Tab
2. 点击「创建快照」
3. 输入备注（可选）
4. 确认

**自动创建：**

每次创建 / 修改 / 删除记录时自动创建 `on_change` 类型快照，备注包含操作描述。

### 查看快照列表

在「快照」Tab 查看所有历史快照，按时间倒序排列。

### 版本对比

选择两个快照版本进行 diff，展示：

| 变更类型 | 说明 |
|---------|------|
| 新增 | 该记录在新版本中存在，旧版本中不存在 |
| 删除 | 该记录在旧版本中存在，新版本中不存在 |
| 修改 | 两个版本中记录值不同 |

### 回滚

1. 选择目标快照
2. 点击「回滚到此版本」
3. 系统将当前解析记录恢复到快照状态
4. 回滚操作本身也会创建 `on_change` 快照

## 权限

| 操作 | admin | member（dns_edit） |
|------|-------|-------------------|
| 查看快照 | ✅ | ✅（指派域名） |
| 创建快照 | ✅ | ✅（指派域名） |
| 回滚快照 | ✅ | ❌ |
| 删除快照 | ✅ | ❌ |

> 回滚和删除快照仅限管理员操作。
