# 仪表盘

登录后默认进入 `/dashboard`，展示团队全局概览。

## 统计卡片

| 卡片 | 说明 |
|------|------|
| 域名总数 | 按状态分布：正常 / 即将过期 / 已过期 |
| DNS 记录数 | 按类型分布饼图（A / AAAA / CNAME / MX 等） |
| 团队成员数 | 当前成员数量 |
| 近 7 天变更 | 解析记录变更次数趋势 |
| 到期日历 | 可视化展示域名到期月份分布 |
| 即将过期域名 | 30 天内到期的域名列表及剩余天数 |
| 最近活动 | 操作时间线（解析变更、成员变动、指派等） |

## 权限差异

| 角色 | 仪表盘内容 |
|------|-----------|
| admin | 全局统计，所有域名和成员数据 |
| member | 仅指派范围内的域名数据 |
| guest | 无仪表盘访问权限 |
